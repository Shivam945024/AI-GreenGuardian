# 🌍 AI GreenGuardian

**AI GreenGuardian** is an AI-based environmental monitoring system that analyzes pollution data and provides environmental risk insights.

## 🚀 Features

* 🌫️ AQI Monitoring
* 📊 Pollution Data Analysis
* 📈 AQI Trend Charts
* ⚠️ Environmental Risk Detection
* 🤖 AI-based Analysis
* 🎈 Streamlit Dashboard

## 🛠️ Technologies

* Python
* Streamlit
* Pandas
* NumPy
* Plotly
* Machine Learning

## 📂 Project Structure

```text
AI-GreenGuardian/
│
├── app.py
├── requirements.txt
├── README.md
│
├── data/
├── models/
└── utils/
```

## ▶️ Run Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Objective

The main objective of AI GreenGuardian is to convert environmental and pollution data into simple, understandable insights and risk information.
